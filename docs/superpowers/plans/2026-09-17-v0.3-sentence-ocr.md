# HoverTranslate v0.3 — 整句与局部 OCR Implementation Plan

> **For agentic workers:** 若当前环境已提供 superpowers，使用 `superpowers:executing-plans` 按任务执行；可独立审查的任务可使用 `superpowers:subagent-driven-development`，但本项目默认单主会话、串行写入。未安装这些技能时按本文件逐项执行，不为满足技能名称擅自安装插件。以 `- [ ]` 跟踪真实完成状态。

> **2026-09-18 更新（当前规则）**：本计划写于"允许列表默认空"时期。来源策略已在 2026-09-18 按用户要求反转为
> **排除列表默认空**——默认**所有应用**都可读，设置里只能逐个排除；无法归属来源与密码/安全控件仍然拒绝。
> 以 `AGENTS.md` 与设计文档 §4 为准；本文中出现"允许列表"的地方属于当时的历史记录，不再是当前规则。


**Goal:** 补足悬停整句与图片文字，同时保持来源、定位和隐私边界。

**Architecture:** AX整句仍优先；只有允许的技术性提取失败才进入ScreenCaptureKit单帧与Vision本机识别；所有结果复用同一请求失效机制。

**Tech Stack:** Swift、SwiftUI、AppKit、ApplicationServices；按阶段加入 Foundation URLSession、Security、NaturalLanguage、ScreenCaptureKit 和 Vision。

**Spec:** `docs/superpowers/specs/2026-09-17-hovertranslate-design.md`

## Global Constraints

- 独立 macOS 原生项目，暂名 HoverTranslate；不属于 Light Balance。
- Swift + SwiftUI + AppKit；部署目标设计为 macOS 14.0，必须由本机 SDK 核对可用性。
- 第一轮只执行 v0.1；每个版本提交实测报告后停止，不自动跨版本。
- 默认右 Option 悬停；设置提供左右 Option 选择；不吞掉或重放原应用事件。
- 仅按用户明确触发读取；应用允许列表默认空；不默认截图、联网或保存原文。
- 不碰 Light Balance、Harness 配置、系统安全策略或其他项目。
- 使用当前发现的 Xcode MCP 工具；不得猜测工具名、参数或已完成操作。
- 普通日志不得包含原文、译文、截图、密钥、HTTP 请求体或响应体。
- 测试使用合成数据；构建成功不代表跨应用交互通过。
- 所有时间、上限和阈值都是设计初值，不是已经测出的性能。

**Interfaces**
- `ExtractionFailure`包含permissionDenied、blockedSensitive、appNotAllowed、unknownOwner、noText、notSupported、positionUnresolved、timeout、stale。
- `OCRFallbackPolicy.allows(_ failure: ExtractionFailure, userEnabled: Bool, captureAuthorized: Bool, sourceConfirmed: Bool) -> Bool`。
- `OCRWord(text: String, rect: CGRect, confidence: Float)`；rect已转换到屏幕点。
- `OCRHitTester.pick(point: CGPoint, words: [OCRWord]) -> OCRWord?`，只按真实命中及阈值选择。

- [ ] 写入策略与空白命中的失败测试。

```swift
import XCTest
@testable import HoverTranslate

final class OCRFallbackPolicyTests: XCTestCase {
    func testSecurityDenialNeverBecomesScreenshotFallback() {
        XCTAssertFalse(OCRFallbackPolicy.allows(.blockedSensitive,
            userEnabled: true, captureAuthorized: true, sourceConfirmed: true))
        XCTAssertFalse(OCRFallbackPolicy.allows(.permissionDenied,
            userEnabled: true, captureAuthorized: true, sourceConfirmed: true))
        XCTAssertFalse(OCRFallbackPolicy.allows(.unknownOwner,
            userEnabled: true, captureAuthorized: true, sourceConfirmed: false))
    }
    func testUnsupportedTextMayFallbackOnlyWhenAuthorized() {
        XCTAssertTrue(OCRFallbackPolicy.allows(.notSupported,
            userEnabled: true, captureAuthorized: true, sourceConfirmed: true))
        XCTAssertFalse(OCRFallbackPolicy.allows(.notSupported,
            userEnabled: false, captureAuthorized: true, sourceConfirmed: true))
    }
}

final class OCRHitTesterTests: XCTestCase {
    func testWhitespaceDoesNotPickNearestWord() {
        let words = [OCRWord(text: "Open",
            rect: CGRect(x: 0, y: 0, width: 40, height: 20), confidence: 0.99)]
        XCTAssertNil(OCRHitTester.pick(point: CGPoint(x: 90, y: 10), words: words))
        XCTAssertEqual(OCRHitTester.pick(point: CGPoint(x: 20, y: 10), words: words)?.text, "Open")
    }
}
```

- [ ] 运行策略/命中测试确认红灯。策略只允许noText/notSupported/positionUnresolved且三条件全满足；其他失败拒绝。
- [ ] 实现单帧截图与来源窗口约束，按需请求授权；不得启动持续录像/音频捕获。[S5]
- [ ] 校验截图sourceRect、显示器/窗口偏移和实际像素尺寸；浮窗排除，800×300初始区域、一次1200×500扩大、4百万像素上限。
- [ ] 在本机Vision识别，提取每词真实子串词框，转换到屏幕点。[S6]
- [ ] 低于0.65置信度、未命中词框或双栏边界不清时拒绝自动结果；面板明确标OCR来源。
- [ ] 使用程序生成的合成英文图片进行OCR集成测试：等宽/比例字体、双栏、换行、灰底、边缘词；不使用用户真实桌面作为仓库测试材料。
- [ ] 加入1x/2x像素比例、负坐标、上/左外屏、截图区域裁切和延迟返回的确定性坐标测试。
- [ ] 单次任务结束/取消释放位图；频率上限800ms，至多一个OCR任务；UI无主线程同步识别。
- [ ] 真实运行验收C组。未授权、敏感窗口和被禁用应用时必须确认截图调用计数为0，而非只是UI没显示。
