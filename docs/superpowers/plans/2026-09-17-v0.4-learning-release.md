> **For agentic workers:** 若当前环境已提供 superpowers，使用 `superpowers:executing-plans` 按任务执行；可独立审查的任务可使用 `superpowers:subagent-driven-development`，但本项目默认单主会话、串行写入。未安装这些技能时按本文件逐项执行，不为满足技能名称擅自安装插件。以 `- [ ]` 跟踪真实完成状态。

**Goal:** 完成主动学习入口、基础设置和本机自用交付，不膨胀成复杂学习平台。

**Architecture:** 保留稳定取词/翻译链路，收藏和解释均由用户主动触发；完成回归、签名/路径记录和清理说明。

**Tech Stack:** Swift、SwiftUI、AppKit、ApplicationServices；按阶段加入 Foundation URLSession、Security、NaturalLanguage、ScreenCaptureKit 和 Vision。

**Spec:** `docs/superpowers/specs/2026-09-17-hovertranslate-design.md`

## Global Constraints

- 独立 macOS 原生项目，暂名 HoverTranslate；不属于 Light Balance。
- Swift + SwiftUI + AppKit；部署目标设计为 macOS 14.0，必须由本机 SDK 核对可用性。
- 第一轮只执行 v0.1；每个版本提交实测报告后停止，不自动跨版本。
- 默认右 Option 悬停；设置提供左右 Option 选择；不吞掉或重放原应用事件。
- 仅按用户明确触发读取；应用允许列表默认空；不默认截图、联网或保存原文。
- 不碰 Light Balance、Harness 配置、系统安全策略或其他项目。
- 使用当前发现的 Xcode MCP 工具；不得猜测工具名、参数或已完成操作。
- 普通日志不得包含原文、译文、截图、密钥、HTTP 请求体或响应体。
- 测试使用合成数据；构建成功不代表跨应用交互通过。
- 所有时间、上限和阈值都是设计初值，不是已经测出的性能。

**Interfaces**
- `SavedEntry(source: String, translation: String, context: String)`，自动生成id/createdAt；不包含窗口路径或截图。
- `LearningStore(directory: URL)`，`save(_ entry:) throws`、`all() throws -> [SavedEntry]`、`removeAll() throws`。
- 应用使用Application Support；测试使用独立临时目录。

- [ ] 写入真实文件往返的失败测试，所有文本为合成数据。

```swift
import XCTest
@testable import HoverTranslate

final class LearningStoreTests: XCTestCase {
    func testExplicitSaveAndDeleteRoundTrip() throws {
        let dir = FileManager.default.temporaryDirectory
            .appendingPathComponent(UUID().uuidString, isDirectory: true)
        defer { try? FileManager.default.removeItem(at: dir) }
        let store = LearningStore(directory: dir)
        XCTAssertTrue(try store.all().isEmpty)
        try store.save(SavedEntry(source: "Settings",
            translation: "设置", context: "Open Settings"))
        let reloaded = LearningStore(directory: dir)
        XCTAssertEqual(try reloaded.all().count, 1)
        try reloaded.removeAll()
        XCTAssertTrue(try LearningStore(directory: dir).all().isEmpty)
    }
}
```

- [ ] 运行LearningStoreTests确认红灯；实现Codable JSON原子写入、目录创建、单条删除和全部清除。
- [ ] 损坏文件不默默清空：显示可理解错误，不覆盖原文件；由用户明确选择清除恢复。错误日志不包含JSON正文。
- [ ] 仅用户点击Save保存；普通悬停、缓存命中、固定卡片不自动收藏。相同原文但不同上下文可分别保存。
- [ ] Explain按钮仅在固定/冻结可交互卡片内显示；点击后才发送新请求，最大输出900tokens，复用同一来源/Keychain/失败策略。
- [ ] 解释请求只要求当前语境含义、简单用法或句子结构，不自动生成词源/音标/大量例句；标明AI解释，不伪装权威词典。
- [ ] 测试保存/删除/重启/损坏文件、无点击不请求解释、禁用云端后不发送新解释；重跑已有测试。
